~/projects/windows-incident-investigation

Windows Security Incident Investigation

DFIR / Incident Investigation

Investigated Windows security events and process activity using available telemetry to review suspicious activity, document findings, identify investigation limitations and provide security recommendations.

Splunk · Windows Event Logs · Event ID 4688 · Process Analysis

What I investigated

  • A suspicious ZIP archive spread through WhatsApp and opened on three computers at Cybugs.
  • Analyzed 429 process-creation records for 9 and 11 September 2026, including process names and parent-child relationships.
  • Searched for commonly abused Windows utilities and user-writable paths. Neither search returned matches.

Limitations I documented

  • Sysmon and the Splunk Universal Forwarder were not installed on the endpoint at the time, and command-line data was not populated.
  • The evidence could not show whether the ZIP executed malicious code. The Trojan label came from a separate VAPT assessment, and I did not identify a malware family.

SOC Monitoring and Threat Detection Lab

SOC / Detection Engineering

Built a security monitoring lab using Splunk, Windows Event Logs and Sysmon to collect telemetry, analyze authentication and process activity, develop SPL detections and create monitoring dashboards.

Splunk Enterprise · SPL · Sysmon · Windows Event Logs · Splunk UF

What I built and investigated

  • Ingested Windows Security and Sysmon logs into Splunk and built a dashboard over 162,927 events.
  • Wrote detections for failed logins, brute-force attempts and suspicious process execution (Event IDs 4624, 4625, 4740, Sysmon 1).

Detection query: brute-force logins

| stats count by Account_Name Source_Network_Address
| where count >= 5
| sort -count
